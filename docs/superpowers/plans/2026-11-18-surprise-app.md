# Surprise — Onion OS app: implementation plan

Spec: the owner's request (2026-11-18) plus `docs/research/onion-internals.md` (the authority for every Onion fact below; cite its sections).

Owner's request: an Onion OS app opened from **Apps → Surprise** that reads a JSON list written to the SD card by the owner's `sync-roms` tool, shows those ~10 games with box art the way Onion's game list looks, and launches the selected one the standard Onion way (Recents, play activity, GameSwitcher keep working). It must be built tonight so the owner can test it on a Miyoo Mini-family device running Onion.

## Global Constraints

- Target: Miyoo Mini / Mini Plus / Mini Flip on Onion 4.3.x/4.4 beta. armv7 hard-float, CFLAGS `-marm -mtune=cortex-a7 -mfpu=neon-vfpv4 -mfloat-abi=hard -march=armv7ve`, `-std=gnu18`.
- Stack: C + **SDL 1.2 + SDL_ttf + SDL_image** linked dynamically (`-lSDL -lSDL_ttf -lSDL_image`), resolved on-device from `/mnt/SDCARD/miyoo/lib` via the inherited `LD_LIBRARY_PATH`. **No SDL2, no json-c, no libSDL_rotozoom.** cJSON (MIT) vendored in `vendor/cjson/` and compiled in. Classic `SDL_SetVideoMode` + `SDL_Flip` path; never write `/dev/fb0`.
- Resolution: 640×480. Ship **no** `full_resolution` file. Still take the surface size from `SDL_SetVideoMode`'s result rather than constants where practical.
- Do **not** copy Onion or RomM source (GPL-3.0). Our code is MIT. Reimplement from the facts in the research doc.
- Build: Colima (already running, arm64, Docker CLI on PATH) + `shauninman/union-miyoomini-toolchain` built natively for arm64, pinned to commit `cfcae30`. In the container: `source /root/.bashrc` gives `CROSS_COMPILE` and `PREFIX`.
- App folder on card: `/mnt/SDCARD/App/Surprise/` with `config.json` (one key per line, keys `label`,`icon`,`launch`,`description`), `launch.sh`, `surprise.png` (74×74 RGBA icon, unique basename), binary `surprise`.
- Input file: **`/mnt/SDCARD/Roms/surprise.json`**, JSON Lines, recents-compatible: one compact object per line, keys in order `label, rompath, imgpath, launch, type`; `imgpath` optional; `type` 5. Paths in the `/mnt/SDCARD/Emu/<SYS>/../../Roms/<SYS>/<file>` form. Values: no `"`, no `:`, each < 256 bytes, line < 1024 bytes.
- Launch contract (research §2): write `/mnt/SDCARD/.tmp_update/cmd_to_run.sh` with exactly `LD_PRELOAD=/mnt/SDCARD/miyoo/app/../lib/libpadsp.so "<launch>" "<rompath>"` (no trailing newline, fflush+fsync), prepend the game's compact line to the recents file (`/mnt/SDCARD/Roms/recentlist.json` if `/mnt/SDCARD/.tmp_update/config/.showRecents` exists, else `/mnt/SDCARD/Roms/recentlist-hidden.json`), `touch /tmp/quick_switch`, `sync()`, exit 0. Cancel (B / Menu) = exit 0 without touching anything. The process must always exit 0 (≥128 shows Onion's fatal-error panel).
- All on-card absolute paths go through one root prefix: compile-time default `/mnt/SDCARD`, overridable at runtime by env `SURPRISE_SDCARD` (used by tests and the preview). `/tmp/quick_switch` is overridable by `SURPRISE_TMP` (default `/tmp`). Paths *inside* surprise.json/recents entries are written verbatim (never rewritten); when the app checks a file exists it maps a leading `/mnt/SDCARD` onto the override root.
- Input keys (SDL 1.2): UP/DOWN/LEFT/RIGHT = arrows, A = `SDLK_SPACE` (launch), B = `SDLK_LCTRL` (back/exit), MENU = `SDLK_ESCAPE` (exit), L1 = `SDLK_e` / R1 = `SDLK_t` (page up/down), START = `SDLK_RETURN` (launch). Handle SIGTERM/SIGINT by exiting cleanly (exit 0).
- Layout mimics Onion list (research §6): header 0–60 with centered title "Surprise"; 6 rows × 60 px from y=60 with `div-line-h` dividers and `bg-list-s` highlight; label at x=20 in the list font, vertically centered, truncated to the list column; `preview-bg` panel blitted at (640−w, 60) and box art scaled down to ≤250 px wide (keep aspect, own scaler — no rotozoom) centered in it around y=240; footer 420–480 `tips-bar-bg` with A "Launch" / B "Back" hints and "n/total" at right. Theme from `"theme"` in `/mnt/SDCARD/system.json` with the fallbacks in research §6; if nothing loads, draw with solid colours and a bundled font fallback so the app never shows a blank screen.
- Empty/missing/invalid surprise.json → a centered message ("No surprise games yet — run sync-roms") and B to exit. Entries whose `rompath` or `launch` doesn't exist on the card are skipped.
- Repo layout: `Makefile`, `src/`, `vendor/cjson/`, `tests/`, `toolchain/`, `App/Surprise/`, `scripts/`, `docs/`. `make` (in container) → `App/Surprise/surprise`; `make test` (host cc on macOS, no SDL) runs unit tests of the non-SDL modules.
- Commits: conventional style, no AI attribution lines (owner rule).

## Task 1: Toolchain + build skeleton

Files: `toolchain/Dockerfile` (FROM the union toolchain image or builds it; pin `cfcae30`), `scripts/build.sh`, `Makefile`, `src/main.c` (placeholder: SDL init, fill screen, wait 1 s, exit 0), `vendor/cjson/cJSON.{c,h}` (fetch upstream DaveGamble/cJSON release tag v1.7.18 with its LICENSE), `.gitignore` (`App/Surprise/surprise`, `dist/`, `build/`, `.superpowers/`).

- `scripts/build.sh`: builds the docker image `onion-surprise-toolchain` if missing (natively, arm64), then runs `make` inside with the repo mounted at `/root/workspace`. Extra args pass through to make (e.g. `scripts/build.sh clean`).
- Makefile: cross target uses `$(CROSS_COMPILE)gcc`, `-I$(PREFIX)/include -Ivendor/cjson -Isrc`, `-L$(PREFIX)/lib`, strips the output. `make test` target builds `tests/*.c` + the pure modules with host `cc` (stub for now, real in Task 2). `make clean`.
- Done when: `scripts/build.sh` produces `App/Surprise/surprise` and `file` reports `ELF 32-bit LSB executable, ARM, EABI5 … hard-float` (or equivalent), and `readelf -d` shows NEEDED only libSDL-1.2/libSDL_ttf/libSDL_image/libc/libm/libpthread-family. Record the exact outputs in the report.

## Task 2: Core logic (no SDL), unit-tested on host

Files: `src/paths.{c,h}` (root prefix, `/mnt/SDCARD` mapping), `src/games.{c,h}` (load surprise.json → array of entries {label, rompath, imgpath, launch, raw_line}; validate the value constraints; skip invalid lines and entries whose rompath/launch don't exist; cap at 64 entries), `src/launch.{c,h}` (build cmd string; write cmd_to_run.sh; recents prepend: write the entry's compact line (re-serialized in `label,rompath,imgpath,launch,type` order, omitting empty imgpath) as line 1, then the old recents lines except any whose `rompath` equals ours; write via temp file + rename; touch quick_switch; sync), `tests/test_main.c` (tiny assert runner, uses a temp dir as `SURPRISE_SDCARD`).

Tests must cover: valid line parsed; spaces-in-path handled; missing imgpath ok; line with `:` or `"` inside a value rejected; field ≥256 B rejected; non-existent rom skipped; missing file → 0 entries, no crash; exact cmd_to_run.sh bytes (no trailing newline); recents prepend with dedupe and with recents file missing; `.showRecents` toggles which recents file; quick_switch created.

## Task 3: UI (theme, list, art, input) + headless preview

Files: `src/theme.{c,h}` (system.json → theme dir → config.json list/title/hint fonts, sizes, colours; skin image lookup chain; fallback font search order: theme list font → `/mnt/SDCARD/miyoo/app/wqy-microhei.ttc` → `/customer/app/Exo-2-Bold-Italic.ttf` → bundled `App/Surprise/res/font.ttf` (a permissively licensed font, licence file next to it)), `src/ui.{c,h}` (render frame per layout; nearest/box-filter downscale for art; text truncation with "…"), `src/main.c` (init, load games, loop, key handling, signals, launch/exit), `scripts/preview.sh` + `toolchain/preview.Dockerfile` (native Linux arm64 Debian with `libsdl1.2-dev libsdl-ttf2.0-dev libsdl-image1.2-dev`, builds the same sources for the host, runs with `SDL_VIDEODRIVER=dummy` and `--screenshot out.bmp` against `tests/fixture-card/` (a fake card: system.json, a theme folder with a few skin PNGs or none, Emu/GBA/launch.sh, Roms/GBA/*.gba + Imgs/*.png, Roms/surprise.json), converting to PNG in `build/preview/`).
- `--screenshot <file>` (debug flag): render first frame (and optionally `--select N`) to a BMP and exit 0.
- Done when: cross build is clean with `-Wall -Wextra` and no warnings, and the preview produces a screenshot showing header, 6-row list with highlight, box art, footer; plus an empty-state screenshot.

## Task 4: Packaging, dev helpers, docs

Files: `App/Surprise/config.json`, `App/Surprise/launch.sh` (cd to its dir; run `./surprise`; always `exit 0`; log stderr to `log.txt` in the app dir, truncated each run), `App/Surprise/surprise.png` (74×74 RGBA gift icon, generated by a committed script `scripts/make-icon.py` or similar using whatever is available on the Mac — Pillow via `uv run --with pillow`, or `sips`), `scripts/package.sh` (→ `dist/Surprise-<version>.zip` whose root holds `App/Surprise/...`, extract into SD root to install), `scripts/deploy.sh` (rsync/scp `App/Surprise` to `root@<host>:/mnt/SDCARD/App/` over SSH, host as arg), `scripts/make-surprise-json.py` (stdlib only; given a mounted SD card path, picks N=10 random games that have `Imgs/<stem>.png`, reading each `Emu/<SYS>/config.json` for rompath/imgpath/extlist/launch, and writes `Roms/surprise.json` in the exact format; honours the value constraints; `--dry-run` prints), `README.md` (what it is, install, build, test, scripts), `docs/surprise-json.md` (the file contract for sync-roms, with examples and constraints), `docs/device-testing.md` (tonight's checklist, including the UNVERIFIED items from research: MainUI's recents rompath form, background orientation, Mini Flip, GameSwitcher duplicate check, log.txt location).
- Done when: `scripts/package.sh` produces the zip with the ARM binary inside, and `make-surprise-json.py` run against `tests/fixture-card` writes a file the app's tests parse.
